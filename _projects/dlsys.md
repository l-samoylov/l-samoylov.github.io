## Overview
Built Needle, a lightweight deep learning framework from scratch, implementing automatic differentiation, tensor operations, neural network layers, and optimization algorithms to train deep learning models without relying on PyTorch or TensorFlow.
## Topics Covered 
- **Automatic Differentiation**: Implemented computational graphs and reverse-mode automatic differentiation with custom forward and backward operations.

- **Neural Network Library**: Developed tensor operations, neural network modules, loss functions, and optimizers.

- **Model Training**: Implemented and trained neural networks, including a ResNet-style architecture for MNIST classification.

- **Deep Learning Systems**: Memory management, tensor computation, and efficient execution of deep learning workloads.
