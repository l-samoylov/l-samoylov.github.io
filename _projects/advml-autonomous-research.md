# Autonomous Research Agent

## Overview
Built an autonomous research agent using DeepSeek V1 via OpenRouter to independently explore, implement, and evaluate code optimizations under a fixed compute budget. Designed the agent to iteratively propose changes, execute experiments, evaluate results, and refine its approach with minimal human intervention.

## Topics Covered
- **Agent Orchestration:** Implemented a Python finite-state machine (FSM) to coordinate autonomous code generation, execution, evaluation, and iterative improvement.

- **Context Management:** Developed context compaction strategies to manage limited context windows during long-running agent sessions.

- **Checkpointing & Recovery:** Implemented checkpoint management and rollback mechanisms to recover from failed experiments and preserve successful changes.

- **Autonomous Experimentation:** Enabled iterative code optimization and benchmarking, achieving an evaluation score of 0.735 across three one-hour runs.

## Key Takeaways
LLM Agents, Agent Orchestration, Autonomous Research, Context Compaction, Checkpointing, Rollback, Code Optimization, Experiment Automation
